## 引用与维护边界

`related` 是相对本 `SKILL.md` 指向其他实际 `SKILL.md` 的可选数组。本次从实际方法引用整理了 26 条关联候选，表达“可能有用”，不自动选择、归档或执行依赖。没有关联的方法不需要空数组或重复技能清单。需要另一方法时，当前 agent 根据目的、实际描述及版本判断，并在联合选择中明确选入；未提供的文件不能当作已读。

每份 SKILL 的执行边界不依赖库根说明。可选的 [FILE-REFERENCES.md](../../../../skills/FILE-REFERENCES.md) 是当前库维护参考；选择归档以实际提供的文件组为准，不能假定库根文件或另一技能已进入旧任务。历史只使用当时归档，缺失、损坏和未执行分别表达。

增删编辑无需重编 CLI。Hub 监听/刷新只重建派生目录及关系，不改技能正文，不替模型选择方法。删除或移动文件时维护者核查入链；错误由目录诊断暴露，不能自动编造同名命令或默默重写正文。维护入口见 [skills/README.md](../../../../skills/README.md)。
