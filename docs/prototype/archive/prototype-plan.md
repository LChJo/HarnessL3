## 模型契约 v0.1（原型）

- `.c4` 是对象、关系、说明与视图的唯一权威模型；Web 的数据与布局只由 LikeC4 解析派生。
- 对象以稳定逻辑名标识，标题和源码路径可变；关系使用有语义的 relationship kind。
- 元数据包含 `source`（源码事实/文档/推断）、`evidence`（稳定证据 ID）、`status`。来源版本、文件 SHA-256 与片段记录在 `evidence.json`；它只保存证据，不复制对象数据库。
- 代码 include 和 CMake link 只能证明静态依赖；动态调用图只在人工核对调用点后加入，并明确声明不是运行时追踪。
- 仅核对选择的文件与对象，不宣称覆盖整个项目、所有函数或运行行为。
- 索引、布局、事件与本机源路径覆盖项放在忽略目录或本机数据目录，按模型和来源工作区身份隔离。
- 不存在的旧架构对象不按历史文档补造；在审查记录中保留偏差。

## 推进顺序

1. 调查当前源码、确认模型粒度与证据。
2. 先运行缺失能力测试，记录 RED。
3. 生成模型并实现解析、证据、日志适配和 Web。
4. 执行测试、真实文本编辑/非法模型恢复、浏览器审查。
5. 记录模型适用范围、局限、可用性问题；同步基准与使用说明。

## 范围边界

本轮不宣称 A01–A10 全部验收通过。多项目登记、自动 worktree 生命周期、通用 agent 日志支持、完整语义同步和数值 SLA 留在后续；Web 人工拖拽写回不属于本轮目标。
