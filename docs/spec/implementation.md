# 实施顺序与原型差距

规格v1.0。M0准备工作已完成；用户现已授权从M1推进到第一个完整可用版本。M1–M4的实际实现、测试及平台范围见[实施状态](../implementation/STATUS.md)，下文保留各阶段的完整退出条件，不因局部测试通过缩小目标。

## M0 开发准备

冻结v0.16交互、原型/历史下沉，形成当前基准、正式spec、Schema与示例、验收矩阵；白名单回收临时产物，保护源码/技能/模型/档案。交付核验结果在[原型清理记录](../prototype/CLEANUP.md)，不将旧报告重计为正式验收。

## M1 工程与工作区基础

建立npm工程的正式模块入口与Node24工具链，提取公共CLI/服务用例边界、配置/Schema校验、目标解析、项目/已有worktree登记、单用户服务发现/启动/停止和只读Web入口。保留原型入口作为比较依据，直到正式路径有独立验收。

正式代码按CLI/core/service/web分模块隔离，测试使用独立数据根。只读目标解析与注册先完成，再启用运行写入。先做Node SQLite worker加载/查询/故障传播的技术验证并锁定实际patch版本；不能因node:sqlite可import就跳过三平台验收。

退出条件：TC01–03、TC22–23对应M1场景通过；init不覆盖、无Git工作区创建/删除、并发启动不产生多主服务。此时可以接真实已登记项目的轻目录，不代表完整上下文链已交付。

## M2 模型、上下文、技能与持久化

先实现单worktree内的权威文本解析/身份/别名/证据，再实现不可变归档与提交日志、混合查询、联合选择、按需文件读取、历史查询与SQLite重建；最后扩展到两个并行已有worktree的相同用例。模型迁移只通过明确映射进行，不重写原型档案。

退出条件：TC02–06、TC09、TC13–19、TC20/25的核心场景通过。故障恢复、幂等和版本拒绝是核心要求，不留到发布后补。用户技能保持普通文件，升级不得覆盖编辑；SQLite丢失可恢复查询，不丢事件/快照。

## M3 双日志观测与同步闭环

固定Codex0.162.1和Claude Code2.1.212首批兼容目标，取得脱敏真实样本后分适配器实现；显式绑定、增量检查点、去重/缺口/未知优先于动画。随后接入源码epoch、扫描策略版本、proof/CAS与阶段关闭。

退出条件：TC07–12通过，宿主日志及配置原件不变；未知格式/工具不推断成功读取，未同步任务保留真实状态。不安装Hooks、不启动agent，不把工具日志中的脚本执行为采集方法。

## M4 Web接入、迁移与首版验收

冻结的上下脑图接入正式快照/事件，保留Slate和逐层文件夹。完成历史/C4、手机、离线资源、显式原型导入dry-run/apply、GC以及三平台npm包安装测试。MGRP只是可用示例，所有核心路径必须也能在另一仓库运行。

退出条件：所有正式场景有实际结果/范围；性能基线已测，若需数值门限另作确认。发布前验证包内容、技能许可、source map/日志中无本机秘密、服务无固定MGRP路径；是否向公共npm发布由另行授权决定。本轮不发布。

## 已知问题与实施期验证

| ID | 当前事实 | 处理位置与完成标准 |
| --- | --- | --- |
| V-P01 | 原型浏览器缓存重试曾0≠1，复跑通过，原因未定位 | M1/M2隔离夹具中记录known/批次/加载代次，复现后修复；无固定sleep或无限重跑；正式门禁不能借原型复跑替代 |
| V-P02 | 原型服务写死MGRP路径/项目、4317及最近日志假设 | M1/M3以registry+明确目标/日志替换，通过第二仓库和并发session验证 |

| V-P04 | Node24.12 SQLite API仍在活跃开发且同步 | M1 worker适配与工具链验证，M2恢复，M4三平台测试；不把数据库设为唯一存本 |
| V-P05 | 文件系统不提供全目录原子源码快照 | M3双扫描/epoch/CAS，只声明已核验到明确版本；变动后回pending |

这些是已写定失败处理的兼容/实现验证事项，不是未决产品范围。远程服务、多机共享写、图形写回、自动worktree生命周期、额外agent、Hook/agent启动、永久历史删除均不属于首版，不阻挡本规格开工。

执行前确认目标worktree/分支和所用版本。用[验收矩阵](acceptance.md)选择失败测试，实际执行RED→GREEN，再同步模型/证据或记录无语义变化。完成后更新实现状态与已验证范围，不把计划文字自动变成通过记录。开发里程碑写终端summary；产品任务历史由HarnessL3自身文件保存，两者不替代。
