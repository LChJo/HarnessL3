## 规格的权威边界

- 项目基准负责目标、约束与已确认决策；本目录负责这些决策的实现契约。原型与研究是依据，不覆盖当前规范。
- JSON字段与合法值以本目录的Schema为准，命令语法/退出码以CLI文档为准；其它文档引用它们，不维护另一套字段定义。
- 对目标、范围、数据权威、隔离或采集方式有影响的调整，先讨论影响，再同步基准/本目录/验收。普通实现细节可在这些约束内直接维护。
- 正式验收场景按实际范围推进，状态与证据单独记录。原型45项程序、34项界面集成等历史结果只证明原型切片，不等于正式CLI通过。

## 本轮已经锁定的选择

Node.js+TypeScript、npm分发、三平台；由现有agent主动调用CLI；只登记已有worktree；文件保存任务/事件/快照，SQLite只作派生索引；首批Codex与Claude Code只读已有日志，不装Hooks、不启动agent、不增设规划模型。最终UI采用Slate连线脑图，技能为Hub→实际文件夹→skill名称→文件引用。
