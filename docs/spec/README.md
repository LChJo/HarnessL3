## 规格的权威边界

- 项目基准负责目标、约束与已确认决策；本目录负责这些决策的实现契约。原型与研究是依据，不覆盖当前规范。
- JSON字段与合法值以本目录的Schema为准，命令语法/退出码以CLI文档为准；其它文档引用它们，不维护另一套字段定义。
- 对目标、范围、数据权威、隔离或采集方式有影响的调整，先讨论影响，再同步基准/本目录/验收。普通实现细节可在这些约束内直接维护。
- 正式验收场景按实际范围推进，状态与证据单独记录。原型45项程序、34项界面集成等历史结果只证明原型切片，不等于正式CLI通过。

## 本轮已经锁定的选择

Node.js+TypeScript、npm分发、三平台；由现有agent主动调用CLI；只登记已有worktree；文件保存任务/事件/快照，SQLite只作派生索引；首批Codex与Claude Code只读已有日志，不装Hooks、不启动agent、不增设规划模型。最终UI采用Slate连线脑图，技能为Hub→实际文件夹→skill名称→文件引用。

基准0.22新增D15：安装运行时skill后所有任务先经L3组织上下文与筛选技能，参考1%触发门槛；有交接的subagent继承，独立子任务单独建档，连续任务复用且允许空选。入口恢复不递归，缺有效目标/能力真实报告；不改变既有Gitworktree、主动调用、无Hook/agent启动边界。FR15与TC27定义新增范围，真实宿主行为仍需验收。

基准0.24引入首次接入确认/拒绝回退与后台链接；0.25进一步要求当前大模型直接阅读项目、维护LikeC4结构/证据并报告初始化进度，CLI只标机械scaffold-ready、不代替语义覆盖。可视化提示移到实际上下文返回后，仅显示格式化链接。默认用户服务常驻单实例，登录码/浏览会话与进程期限独立；FR02/07/12/15及TC03/23/27定义增量，实际范围见实施状态。

基准0.26将提示进一步精简为单独一行“查看可视化过程”文字超链；首屏任务数据返回前只显示加载状态，重复SSE刷新不得取消同目标的首个读取。任务格式判断复用服务已加载日志，保留所请求归档的完整性检查。FR07/12/14/15及TC21/27定义本次增量，不新增数值SLA。

基准0.27将D06的Git持久化边界加入CLI入口规则：模型/项目配置/证据/别名随相关源码版本管理，项目文档和项目技能按实际归属纳入，本机运行数据及外部技能库排除。仅给提交建议，不自动暂存/commit/push，不改旧回执；FR03、TC06及存储/CLI契约同步。

基准0.28细化D10/FR07：五类和技能展开仅保留命中及祖先路径，未命中合并为“…”并进入独立搜索/分页列表；目录不再全部铺入脑图。完整内容仍来自当前目标或当时归档，浏览不计读取；TC20/21增加大目录、页面返回与列表操作验收。

基准0.29修复D09/D10及FR07/12的两个投影/登录缺口：父对象自身正文返回时，展开后仍有该实体的正文命中叶子和输出连线，计数不重复、子对象不补读；同浏览器有效会话可重复打开原链接，不延长12小时期限。无有效会话时仍要求5分钟内未消费的登录码，401显示登录恢复状态；TC21/23增加回归范围。

基准0.30按用户要求移除网页任务创建入口和“已关闭”标签，任务由agent通过CLI创建，已有任务的显式网页请求、只读与历史边界不变。FR07及TC21按Web规格检查页面、下拉、历史及空白工作区，浏览验证使用CLI预先建立的隔离任务。
