# 产品规格

规格v1.0；实现及平台验证见[实施状态](../implementation/STATUS.md)。约束入口：[项目基准](../PROJECT_BASELINE.md)。

## 用户与结果

主要用户是正在受管理Git worktree中工作的agent，以及查看其上下文组织的人。开发者提供任务目的，现有agent利用稳定简述，成批选择需要的项目知识与工作方法；CLI返回可追溯的上下文和技能文件引用。agent随后使用原有工具正常工作，并在阶段结束前核对源码变化与模型。

基准D15确认全任务/1%先尝试L3，连续有效任务复用、无需材料显式空选。首次未登记经agent通用询问窗口确认，同意后机械接入及当前大模型建模，拒绝/取消本任务普通执行且不重问，已有授权复用。0.25将可视化提示改为实际上下文返回且必要技能正文读取后显示，仅使用格式化链接；初始化进度与语义覆盖由当前大模型如实报告。宿主遵守文件型skill，不增加Hook/agent启动；引导恢复不递归。

成功结果是：目标工作区明确，所选数据能快速定位和重复利用，Web可解释输入到上下文包的真实组织，60天内能够恢复当时的批次与文件。模型调用次数不由图的层级决定；不把“响应生成”描述为“模型理解”。

## 首版边界

| 首版包含 | 首版边界 |
| --- | --- |
| 多项目和已有worktree登记、明确选择与恢复 | 不创建、切换或删除Git worktree/分支 |
| agent直接读写LikeC4、说明、证据与普通技能文件 | 不强制Model API/MCP或对象CRUD，不提供图形写回 |
| 混合批量披露、跨层正文读取、独立请求并发 | 不为每个节点调模型，不替现有agent做规则化技能选择 |
| CLI自动启动/复用本机服务、按需Web | 不启动agent、不选择模型提供方、不管理API密钥 |
| Codex和Claude Code的限定版本日志观测 | 不安装Hooks、不注入工具、不扫描无关会话，不承诺全量覆盖 |
| 文件历史、派生索引和只清派生的GC | 超期退出默认查询，首版不提供历史永久删除 |

## 标准工作流程

初始化分成机械接入与语义建模：CLI的init只保留确定性的缺失文件建立、身份登记、技能库首建和模型校验；返回scaffold-ready、实际对象/关系/视图数量及交给当前agent的后续动作，语义状态为not-assessed。当前大模型使用已有文件工具读取项目说明、目录及关键入口，直接编写或增量补全LikeC4层次、真实依赖和来源证据，报告阅读→建模→校验进度。覆盖范围由实际阅读与检查支持；机械成功、目录列表或单个边界模板不算项目结构建模完成。无需另起模型、额外API或脚本推断业务语义；CLI的解析、存储和索引等确定性基础设施保留。

可视化提示在task select/query/handoff的实际上下文返回且所需skill正文读取后显示，仅为单独一行“查看可视化过程”文字超链；不附使用/选择说明、前后缀、裸网址或常规到期提示，不提前显示或逐组重复。默认后台为当前用户、默认数据根的一份常驻服务，无空闲超时；网页一次登录码/已登录会话与进程生命周期独立。

1. 已有Git仓库/worktree由外部工具准备。首次窗口确认后机械接入，当前大模型阅读真实来源并直接补全模型、关系、证据及视图，报告进度/校验/覆盖后恢复任务；拒绝/取消普通执行。已有模型保留身份，旧历史不回写。
2. 当前agent调用task start，提供目的、工作区及可选调用方会话声明，取得上下文筛选提示、顶层简述、Skill Hub原则和实际技能轻目录。
   主agent按实际任务建档而非每条消息新建。subagent已有有效父L3交接时核对并复用，只在受托范围内补充查询/读归档，不重选技能或关闭父任务；没有可用交接的独立子任务自行创建和关闭自己的任务。父子关系是交接声明，不新增专属CLI字段、权限隔离或自动日志绑定。
3. agent一次提交所选目录/正文目标及含理由的技能集合。必要时先成批披露更多简述；已知目标可跨层直达，不必逐层点击或逐节点调用。
4. CLI核对目标、模型、源码及技能目录版本，归档实际返回内容。交接先返回上下文包与版本化技能引用；正文/附件按需读取。技能关联只是候选，不自动加入集合。
   实际上下文返回且必要skill正文读取后，agent用web open --no-open取得真实任务链接，只输出单独一行“查看可视化过程”文字超链；不附使用/选择说明、裸地址或常规到期说明，空选也不增加说明。Web失败不阻断CLI。
5. Web按已记录请求、披露与返回投影命中；加载任务或目录更新不自动展开。浏览层级与agent读取分别计量。
6. agent使用普通文件工具继续工作。只读日志适配器记录能识别的真实工具操作；源码变化立即标待核验，未采集操作保持未知。
7. 阶段结束前，agent更新模型/证据或提交无语义变化核验依据，CLI检查版本和证据。上下文任务关闭只记录本组织阶段的状态，不证明agent整体执行成功。
8. 历史查询恢复当时的输入、各批次、五类组织、技能方案和上下文包；查看不续期。

## 功能需求

| ID | 要求 | 完成条件 |
| --- | --- | --- |
| FR01 | 项目与worktree登记 | 多个仓库、多个已有worktree均可定位；目标冲突明确拒绝，操作不改变Git检出 |
| FR02 | 初始化与配置 | 首次窗口确认后CLI机械接入；当前大模型读取来源、直接编写/补全对象/关系/证据/视图并报告进度，核对覆盖后才报告语义初始化完成。scaffold-ready/解析成功不替代建模；已有内容/身份保留，拒绝/取消普通执行 |
| FR03 | 文本模型维护 | agent可直接编辑LikeC4；对象/关系有稳定身份、来源、状态、证据与版本；非法模型不冒充最新。入口直接建议Git项目将模型/配置/证据/别名与相关源码一并版本管理，项目文档/技能按归属纳入，本机运行数据排除，提交遵守已有授权 |
| FR04 | 稳定简述与批量读取 | 一次混合多个expand/read，支持跨层、去重、缓存与并发；返回范围精确，不隐含整棵子树 |
| FR05 | 一次联合技能选择 | 同一任务一次确认集合，空集合与未知有别，旧目录版本拒绝；默认只交接文件引用 |
| FR06 | 技能文件维护 | 随包方法首次成为可编辑文件，实际增删改自动更新目录与诊断；刷新不修改正文和旧方案 |
| FR07 | 脑图与C4投影 | 同一无限画布、初始五类、Slate；逐层只展命中及祖先，未命中以“…”进入独立搜索/分页列表，技能文件夹/成员一致。首屏数据到达前显示加载状态，同目标刷新合并且不取消首个读取；C4按需展示同一文本的静态结构 |
| FR08 | 真实只读观测 | 两类日志均有版本化样本；绑定会话/工作区，正常、失败、未知和覆盖缺口分别表达 |
| FR09 | 源码同步闭环 | 变化即时待核验；proof检查与源码代次绑定；并发变化不能被旧结果清除 |
| FR10 | 历史与恢复 | 60天检索、分页、批次组织、当时C4/技能文件可恢复，查看不续期，缺失或损坏明确报错 |
| FR11 | 可重建派生数据 | 每worktree隔离索引/缓存，删除索引后从文件重建，不产生虚假的读取或改写历史 |
| FR12 | 通用命令与分发 | npm包提供harnessl3；文本/JSON、非交互输入、退出码与错误三平台一致。实际上下文返回后仅输出独立的“查看可视化过程”文字超链；常驻服务与网页访问期限分别表达，JSON进程不提问 |
| FR13 | 迁移与GC | 原型导入显式、默认dry-run、幂等且保留源；GC只回收确定可重建/未提交临时产物 |
| FR14 | 性能可测 | 冷热定位/读取/写入/更新/恢复有固定测量方法，报告P50/P95和资源开销，不空口承诺最优 |
| FR15 | 全任务入口与子任务继承 | 全任务/1%先尝试L3，复用有效任务、允许空选；首次经窗口确认并由当前大模型建模/报进度，拒绝/取消普通执行，已有授权复用。实际上下文返回后仅输出独立文字超链，不附使用/选择说明；父交接继承/独立子任务和引导不递归，宿主行为与API分别验证 |

## 状态表达

用户可见页面和提示只呈现任务数据、操作及必要状态，不显示开发注释、实现解释或教学标语；工程说明不嵌入交付界面。领域简述、选择理由与实际来源/范围数据仍为产品内容。
模型有效性、源码新鲜度、采集覆盖、上下文请求/返回、技能选择/文件返回各自独立。合法模型可以待核验；观察到写入不代表知识已经同步；选择技能不代表执行；父层命中只聚合已知后代，不代表整个模块已读。

输入是本任务目的与实际请求，输出是交给agent的上下文包及引用，均不等于完整聊天或模型最终回答。未记录的工具活动不能用文件变化、静态关系或相邻时间补成执行路径。

验收映射见[验收矩阵](acceptance.md)。交互细节只在[最终原型设计](../prototype/DESIGN.md)维护，公共数据契约见[CLI规格](cli-contract.md)。
