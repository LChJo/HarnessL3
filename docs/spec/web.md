# Web投影与最终设计接入

规格v1.0，实现和平台验证见[实施状态](../implementation/STATUS.md)。视觉沿用[已确认v0.16](../prototype/DESIGN.md)的Slate设计，可见节点与目录交互按[当前基准](../PROJECT_BASELINE.md)的v0.30增量执行；冻结原型不回写。正式数据来自[CLI公共用例](cli-contract.md)及[归档](storage.md)。

## 展示职责

首版Web是本机只读观测与原有检索操作的界面。项目/worktree选择器选择服务目标，不修改Git检出。主页保持状态总览，原文和诊断按需打开；不增加架构介绍落地页、旧界面入口或第二套知识编辑器。

正式界面及用户可见提示仅呈现任务数据、操作和必要的加载/连接/错误状态；不添加开发注释、实现解释、教学标语或自我说明。移除顶部画布介绍、泛化的展开指导、计数解释、输入/输出说明及技能/结构/历史详情中的固定注释。实际知识简述、选择理由、来源/范围/版本数据与用户明确打开的原文/诊断仍按事实显示；工程解释维护在规格与工程记录。

选择理由疑似在输入前丢字时，节点/详情显示“原记录可能存在编码损坏”，详情可展开“查看理由原文”。仅对替代字符U+FFFD或至少6个问号、连续至少3个且问号占非空白字符一半以上的明显模式给提示；这是显示诊断，不拒绝合法请求，也不恢复原文字。普通中文、提问及`??`/`?.`代码表达保留原样；正式与旧格式方案共享同一规则，历史记录和原始归档预览不改写。

输入、五类上下文、上下文输出、下方Skill Hub与技能方案全部共享同一世界坐标与手势。首屏不展开子层；用户展开状态与相机是视图状态，不写入LikeC4、不变成模型任务路径，也不计读取。自动布局是可重建派生结果，历史任务保留当时组织所需数据，布局算法升级不能替换历史内容。

v0.28按用户确认调整可见前沿：保留五类入口，各展开层只展示实际命中及连接它们的祖先；未命中兄弟合并为一个“…”节点。该节点的数量为此层聚合项数，不冒充正文命中数。点击进入独立的全部节点列表页，显示该分支完整后代的名称、路径、简述及实际状态；可搜索、按命中筛选、每页50项，不为全部节点绘制脑图或连线。列表使用URL定位，刷新及浏览器前进/后退有效；同目标返回保留原画布相机与展开状态。

v0.30移除输入卡片/历史栏的新建任务入口及空白工作区的创建表单，任务由现有agent经CLI建立；未选任务显示真实空状态。标题、任务下拉和历史列表不显示“已关闭”标签，底层关闭记录、只读约束与既有任务的显式选择操作不变。

## 读模型

Web从同一核心用例获得当前项目/工作区、模型诊断、来源新鲜度、任务/批次、轻目录、实际返回包、技能选择/文件引用、采集覆盖及可用C4。公共持久记录为输入；客户端五类树、连线、聚合数、动画与可见前沿均为派生展示。

| 区域 | 实际依据 | 不可推断 |
| --- | --- | --- |
| 输入 | task目的、绑定目标、声明会话与请求来源 | 完整系统提示或完整聊天 |
| 对象 | 批次实际披露/返回对象及原祖先定位 | 父层或端点正文已读 |
| 关系 | 返回对象的直接关系/独立观测引用，保留来源/推断状态 | 连线等于执行先后或因果 |
| 来源 | 返回内容的来源声明与引用关联 | 声明即事实证实 |
| 证据 | 实际返回的证据引用、明确请求后返回的片段范围 | 引用已返回等于整个源码文件已读 |
| 版本 | 模型、来源指纹、扫描策略、worktree、核验范围 | 分支/commit即全部源码已同步 |
| 输出 | 累计实际上下文包、版本化文件引用和错误范围 | 模型已理解、最终回答或代码产物 |
| Skill Hub | 当时选择、理由、group、文件清单/指纹与独立读取回执 | 已选择或文件返回等于技能已执行 |

现有原型不保存完整业务源码副本。正式v1同样只自动归档上下文/技能与引用；历史中打开当前源码须明确“预览当前源码”，不能以当前片段冒充当时读取。日志只记录有依据的路径/范围/结果，不反向填入未知的正文哈希。

## 状态与连线

- 首屏目标数据未返回时只显示加载状态，不展示空任务输入/输出或零命中图。数据就绪后先定位相机再绘图；加载失败可重试。同目标SSE刷新合并为在途读取后的补取，不取消首个读取；切换目标仍取消旧请求并拒收旧响应。
- 任务格式判断复用服务已加载且已验证的日志，不为打开已记录任务重复读取无关历史的全部引用；所请求任务的快照/字节完整性检查保留。
- 初始五类为定位入口。已披露简述、待获取候选、请求中、实际返回、引用、关联版本、错误与未知分别表示；实际返回可以同时点亮多个类别。
- 折叠父层聚合已知命中；分类计数不可简单求和为独立正文数。关系端点或来源边界只是定位，不能额外点亮为正文返回。
- 对象自身正文已返回且含子对象时，展开显示指向该原实体的“对象名 · 正文”终端叶子，并保留到输出的命中路径。它只是同一实体的视图投影，不额外增加分类/正文计数；只有后代命中的祖先不生成自身正文叶子，未读子对象仍进入未命中聚合。叶子详情使用当时已返回的原正文，浏览不创建读取。
- CLI选择与网页手动选择保留来源；预设示例明确标为示例，不能冒充agent自主选择。
- Skill Hub默认闭合；打开只展含已选技能的实际文件夹，点击见已选skill，再点见其文件引用。其余文件夹在Hub层合并为“…”；已选文件夹的未选成员同样聚合，点击进入全部或该文件夹的独立技能列表，显示文件数量并可打开详情。尚未选择时完整目录只通过“…”进入列表；显式空选仍保留未选目录入口。命中以实际方案为依据，候选或目录浏览不冒充选择。文件夹保留完整数量和已选数量，旧group/ID/字节优先归档，缺字段明确未知，不用当前目录补旧历史。
- 选中到返回的动画只由真实批次/事件驱动，独立目标不为动效串行。事件到达不自动展开、不强制跟随相机；减少动态效果设置受尊重。
- 错误、采集缺口、最近有效模型、旧任务、部分恢复均有文字标签。Slate色板复用，不用颜色代替事实状态。

## 当前与历史隔离

服务为每worktree发布带单调提交序号的事件；Web按明确目标订阅。事件只提示有新提交，客户端重新取对应已提交状态，不把来自另一目标的ID拼接到当前树。重连按序号补取，缺口则拉完整快照；不能因为重复事件重复增加命中数。

打开历史时固定task及可选batch，使用当时归档。实时SSE可以提示有更新，但不改写已打开的组织；“最终组织”是显式新查询。模型无效、目录变动或另一任务的活动均不覆盖历史。查看/平移/展开/复制不更新最后读取活动。

全部节点页的浏览、搜索、分页及详情定位只使用已返回的模型/目录。正文/目录候选仍需用户显式选择并提交原有批量请求；技能候选及归档预览也保持原有显式步骤。未选技能只有目录文件引用，不能因为列表显示而获得task read权限；旧历史缺少完整目录时保留实际已存范围。

## C4与本机边界

实际上下文及必要技能正文返回当前agent后，用web open --no-open --task取得真实URL，在进度消息中展示一次输出卡片，再继续用户工作。卡片保留Markdown引用块、加粗标题“HarnessL3 · 本次输出”、空白引用行及“↗ 查看HarnessL3的输出”文字超链；不包代码围栏、不附裸地址、使用/选择说明或常规到期文案。卡片不表示工作完成，空选择同样处理，最终答复不重复。宿主TUI决定具体渲染与点击效果，CLI仅提供真实链接。浏览时不创建agent读取。首次未登记经通用询问窗口确认，当前大模型完成语义建模并报告进度；Web的结构来自实际LikeC4，模板/缺少关键模块不冒充结构完成。旧任务保留当时模型，新结构使用当前版本的任务/视图展示。

后台默认在当前用户数据根全局单实例常驻，无空闲退出；网页一次登录码5分钟/一次性、登录后会话12小时，与进程寿命独立。重复打开链接优先复用同浏览器的有效会话，不更换cookie或延长期限，并消费链接中尚未消费的新码。无有效会话时，一次性码仍需有效且未消费；401显示重新登录和取得新链接的恢复指引，不标为本机服务不可用。清除地址栏凭证时保留worktree/task/batch等目标；重新认证不得跳到其它项目。Web不代替用户同意或当前大模型建模。

C4按需加载LikeC4当前有效视图，或历史归档中的当时视图。它呈现静态组成/关系，不负责检索顺序；技能不变成C4对象。旧历史缺图时显示未知，可显式选择“当前结构（非历史图）”，不能静默代替。

正式包提供本地Web资源，默认不依赖外部字体/CDN或外部API。用系统字体或许可清楚的随包资源保留原型的可读性与Slate视觉。布局/相机/展开状态可在本机视图配置中保存，但不是任务事实或权威文本。

服务鉴别与同源规则见[运行架构](architecture.md)。此产品不使用Codux notes/终端summary保存任务，开发里程碑与产品历史分别维护。

验收包含：三平台浏览器、手机触摸、点击锚点、层级隐藏、并发点亮、目录自动变更、双日志未知范围、历史SSE隔离、归档C4及离线资源。具体场景编号见[验收矩阵](acceptance.md)。
