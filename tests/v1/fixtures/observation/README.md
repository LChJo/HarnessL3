# Observation fixtures

`codex-synthetic.jsonl` and `claude-synthetic.jsonl` are fabricated protocol fixtures, not captured user conversations. `__WORKTREE__` is replaced with an isolated temporary directory by the tests. The secret markers verify that transcript text, commands, prompts, patches and tool output are never persisted in normalized observations.

Synthetic fixtures verify parser behavior only. They do not establish compatibility with an installed host version. Version validation requires the separately identified, minimally desensitized real transcript fixtures.

`codex-real-0.162.1.jsonl` was reduced from the explicitly authorized current-project Codex rollout. The real `custom_tool_call` / `custom_tool_call_output` envelopes, `input_text` result block type, AST control structure and numeric result metadata are retained. Session/record identifiers, timestamps, cwd, all paths, bodies and other string literals are replaced. Unsupported command literals become `unsupported-fixture-command`. This real wrapper has multiple children, so its successful aggregate is deliberately **not** evidence that each read succeeded. The independent single-read fixture below provides a separate real success case.

`codex-real-single-read-0.162.1.jsonl` additionally retains the shape of a real, explicitly paired standalone `Get-Content -LiteralPath` read performed by the root agent to check the project README. The wrapper has one awaited literal tool call and immediately publishes that result. Its actual exit code and numeric result metadata remain; filename, cwd, identifiers and all stdout are replaced. This proves the narrowly supported successful single-read shape, without treating aggregate execution as individual success.

`codex-real-failed-read-0.162.1.jsonl` retains one separately authorized, actual standalone read of a nonexistent fixture path. Its uniquely paired real result has `exit_code: 1` and no running session. The AST/control shape, result block types and numeric metadata remain; cwd, nonexistent filename, identifiers, timestamps and every original stdout/error string are replaced. This validates the narrow failed-read result, including `failed`/`nonzero` without claiming returned content. It does not establish cancellation or session-polling compatibility.

`claude-real-2.1.212.jsonl` contains reduced tool pairs from the user's explicitly authorized Claude project directory, using only direct `.jsonl` files. The retained pairs cover Read (text), Edit, Grep, Write and the Bash transcript envelope. Numeric Read ranges and boolean result fields remain; body, patch, query, command description, stdout/stderr, original paths and identifiers are replaced. Bash's command is replaced by a deliberately unsupported compound fixture; it does not establish real literal-shell compatibility. No Glob record was found; Glob behavior is synthetic-only in this evidence set.

Extraction discarded all prompts, chat, thinking, base instructions, metadata passthrough, credentials and user business content. No user log or host configuration was modified. The temporary local extractor was removed after producing the fixtures.

TC10 remains **partial** for real-host cancellation, missing-result and session-polling coverage; Claude failure and Glob are also synthetic-only. A later read-only audit of all 268 directly authorized Claude JSONL files found Read 31, Bash 132, Edit 22, Grep 14 and Write 3 matched calls, no Glob, no unpaired supported calls, no `is_error: true` and no `interrupted: true`. The authorized Codex file had nonzero child-result blocks inside aggregates, which are not proof of an individually failed read. The additional failed-read fixture above was generated separately after that audit. Body-free aggregate evidence is retained locally at `.harness-local/implementation-20261105/observation-real-shape-audit.json`. These counts describe only the explicitly authorized files, not all possible host behavior.
