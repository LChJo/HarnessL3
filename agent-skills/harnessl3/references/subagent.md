# 子任务与 subagent 接入（按需读取）

用于现有 Codex/Claude Code 的受托子任务。L3不启动、选择或调度agent；是否委派及使用什么工具由当前主agent、用户授权和实际宿主能力决定。本文件沿用主skill的全任务入口要求，不在子任务中重复主agent的整体流程。

## 父任务已有 L3 交接

主agent在允许委派时，向子agent提供实际目标worktree/路径、任务ID、委派目的与范围、版本绑定、截至某批次的交接包及所需技能文件引用。可一并提供已按需读取的归档正文，但要说明来源及实际读取者；不把“父agent读过”记成“子agent已调用读取”。不要将父子声明伪装为CLI已观测到的因果。

子agent先核对目标和交接范围：

1. 已给出完整且可核对的交接材料时直接复用；需要恢复或确认批次时，按当前CLI的 `task handoff --help` 使用真实任务ID/批次读取。继承已走过的L3入口，不另做一次联合技能选择。
2. 需要补充上下文时，在允许的目标和范围内使用 `context query` 批量读取；需要已选方法正文时用 `task read` 读取其真实归档引用。参数、版本和文件指纹按当前CLI帮助及契约取得。
3. 只执行指派范围，返回实际结果、读写/核验范围、仍缺材料及有关任务/批次引用。不要关闭父任务、替父任务重选技能或自行扩大范围。父任务的汇总、整体同步和关闭由主agent负责；局部结论不能宣称父任务全量核验。

若任务已关闭、模型/源码变更、目标不符或交接不完整，向主agent返回具体冲突。需要不同技能集合或当前版本的独立上下文任务时，在委派授权范围内建立自己的L3任务；不要把新内容写回旧绑定或替换父任务已归档的选择。

## 没有可用父交接的独立子任务

不要假定“我是subagent所以跳过L3”。使用已明确的已有worktree和本子任务目的，按主skill入口创建自己的任务、一次选择上下文与技能，完成后核验并关闭自己的任务。无需额外材料时提交显式空选择；保持父任务与其它子任务的身份、版本和状态独立。

没有真实目标、运行CLI的工具能力或所需交接材料时报告缺失，由主agent提供材料或决定后续。不能猜“最近项目”、伪造调用成功，或为了接入自动创建Git仓库/worktree。处理安装或入口恢复时避免递归，恢复后再进入实际任务。

## 现有能力边界

当前CLI使用普通task、handoff、query和归档读取兼容子任务，不提供parentTaskId字段、子代理调度或专属权限隔离。父子归属是交接声明，保持在任务说明/返回依据中，不添加未定义的JSON字段。不要把工作流约定说成CLI已经强制限制子agent关闭父任务。

子agent上下文兼容也不代表日志自动接入。只读日志仍需已授权、明确的宿主/会话/绝对路径显式绑定；不递归扫描子会话，不扩展Codex/Claude Code以外的宿主名单。
