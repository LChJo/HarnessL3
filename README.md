# HarnessL3
Similar to Level 3 autonomous driving, it automatically invokes the appropriate skills to complete project development, and is visual, editable, and manageable.

项目仓库：[LChJo/HarnessL3](https://github.com/LChJo/HarnessL3)。

当前建设方向：以 LikeC4 文本维护项目上下文，agent 直接读写文件；CLI 管理多项目及分支 worktree，Web 展示项目图、同步状态与受支持 agent 的读写轨迹。当前处于基准与方案阶段，产品能力尚未实现。
