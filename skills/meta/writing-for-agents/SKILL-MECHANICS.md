# Skill mechanics

The skill-specific branch of [writing-for-agents](SKILL.md). The main file covers writing any document an agent consumes; this attachment covers a selectable Skill Hub method.

## Discovery and selection

Every method keeps a useful name and description. The current model judges the disclosed descriptions against the task; the user may also identify a method or purpose directly. These are selection paths, not installed slash commands. Descriptions cost attention when disclosed, not a guaranteed permanent place in every turn's context.

State applicability and meaningful branches precisely. A user-directed procedure should describe the requested action without turning ordinary work into that procedure. Host-specific invocation flags do not implement the Hub selection contract.

## Independent archives

A selected method archives its own folder. Inline essential behavior and put substantial conditional detail in real attachments in that folder. Every local Markdown link must resolve inside that archive. A project document such as GLOSSARY.md is an optional convention, not a bundled attachment or another required authority.

Additional capabilities are discovered from the current catalog and explicitly selected when needed; another method’s name is neither its returned body nor permission to execute it. Default methods carry no cross-method related list. User-supplied related candidates remain supported and are never automatically selected or archived.

## Splitting and routing

Split only when the purpose or branch earns independent selection. A method can be reference, steps, or both; choose the shape that protects its completion criteria without duplicating shared meanings. Keep a useful description for each independently selectable unit.

Skill Hub derives its directory and classifications from real files. Keep routing guidance about intent and decisions rather than embedding a second fixed inventory in a method. Renaming changes the current path ID; historical selections retain their original ID, group, files and bytes.
