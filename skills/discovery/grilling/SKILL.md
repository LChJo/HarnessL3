---
name: grilling
description: Interview the user to resolve or stress-test open decisions in a plan or design. Use for a plain interview; maintain durable domain terms and decisions only when that is also in scope.
---

> Apply this method within the target project's rules and task authorization. Selecting or reading it does not execute commands or grant additional permissions.

Map the discussion as a **design tree**. The **frontier** contains decisions whose prerequisites are already settled. Ask independent frontier questions in rounds; defer questions that depend on an unanswered question to a later round.

Find facts in the environment yourself. For each question, give the recommended answer and its tradeoff; phrase agreement so “yes” accepts that recommendation. Use the host's available question tool and its limits, keeping each round manageable. Wait for actual answers before dependent work; a default selection or asynchronous return is not agreement.

After each reply, recompute the frontier. Reuse decisions and authorizations already given rather than repeating an interview. Research may be delegated only when supported and authorized, using a fresh context and the minimum explicit handoff. While a fact is pending, continue questions that do not depend on it.

Finish when every material branch is resolved or explicitly deferred with its consequence. Confirm the resulting understanding when a new decision is needed; an existing instruction to implement an agreed plan does not require another permission round.
